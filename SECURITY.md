# Security Policy & Vulnerability Reporting

## Zero-Telemetry Guarantee
MCPShield's browser-based Live Auditor (`docs/`) and offline CLI execute 100% locally. No `mcp.json` files, environment variables, or credentials are ever transmitted over the network.

## Reporting a Vulnerability or Rule Bypass
If you discover a false negative in an OWASP MCP Top 10:2025 detection rule or a security issue:
1. Open a public issue at [https://github.com/BenJackson111/mcpshield/issues](https://github.com/BenJackson111/mcpshield/issues) (redact any real credentials before posting).
2. Or use GitHub's **Report a vulnerability** private advisory button on the repository Security tab.
