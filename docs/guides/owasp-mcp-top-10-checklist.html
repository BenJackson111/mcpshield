OWASP MCP Top 10 (2025/2026) Security Checklist for AI & Platform Engineers

Published October 2026 • By Midas Labs Security Engineering

Why Model Context Protocol (MCP) Configurations Are High-Value Targets

Local and remote MCP servers execute with the permissions of the host developer workstation or production agent container. A single misconfigured mcp.json file can leak cloud credentials (MCP01), allow arbitrary shell execution (MCP05), or expose the agent to prompt-injected tool poisoning (MCP03).

The 10 Mandatory OWASP MCP Controls

MCP01: Token Mismanagement & Secret Exposure       -> Never store sk-*, ghp_*, or DB passwords in mcp.json
MCP02: Privilege Escalation via Scope Creep        -> Never mount / or /etc; scope strictly to ./workspace/sandbox
MCP03: Tool Poisoning & Schema Integrity           -> Enforce additionalProperties: false & SHA-256 schema locks
MCP04: Software Supply Chain & Unpinned Runners    -> Replace npx pkg@latest with exact versions & mcp-lock.json
MCP05: Command Injection & Shell Wrappers          -> Remove sh -c / bash -c wrappers; invoke binaries directly
MCP06: Intent Flow Subversion (Auto-Approve)       -> Prohibit autoApprove: ["*"]; enforce human-in-the-loop
MCP07: Insufficient Auth & Cleartext Transport     -> Require https:// TLS 1.3 and OAuth 2.1 with PKCE
MCP08: Lack of Audit Logging & Traceability        -> Enable 180-day redacted JSON audit logs (EU AI Act Art. 12)
MCP09: Shadow MCP Servers                          -> Require governance owner/purpose metadata & allowlist
MCP10: Context Over-Sharing & Unscoped DB Access   -> Enforce readOnly: true & PII-masked database views
